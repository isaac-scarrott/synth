# 2026-08-06

## One coat, no seams: the session card is the only surface

Feedback, in three beats across one session: "get rid of background on sidebar" → "no, no lines on
sidebar or tabs, get rid — it's the actual content layer e.g. terminal that is draggable" → "stop
the hover border just before the border radius' start".

The shell had been drawing the sidebar as a room of its own: a `--sidebar-step` tint, a rounded
right corner, an edge shadow, a hairline seam against the content, another hairline under the pane
header, one more above the sidebar foot. All of it is gone. The window is now a single coat
(`--panel` on `.app`) with exactly one kind of surface on it: the raised session card (`.term` /
`.browser`). Nothing else separates sidebar from content — the card's own left edge IS the
boundary.

- **Sidebar** — no fill, no border-right, no radius, no shadow, no foot border-top. The
  `--sidebar-step` token (both themes) and `--radius-panel` are deleted. `--sidebar` itself stays:
  the ⌘? overlay still echoes it.
- **Pane header** — border-bottom dropped. The header floats on the coat like the sidebar rows do.
- **Sidebar resize** — the invisible 9px grab band moves from the sidebar/content boundary to the
  session card's left edge (`--sidebar-w + 14px` pane margin), keeping `col-resize`, drag, and
  double-click-to-reset. On hover/drag a 3px strip (`--text-faint`, scrollbar-thumb weight — the
  edge thickening, not a state colour) paints along the card's straight run only, inset 10px each
  end so it stops exactly where the card's corner radius begins. Tabs mode gets a top offset
  override (36px strip instead of the 50px header).
- **Claude Code is a terminal** — the native-chat mock (`.msg` bubbles, raised composer card, send
  button) was unrealistic: Claude Code is a TUI running inside a terminal. The agent pane now
  renders the same `.term` card the shells get, with the transcript as terminal lines (`>` echo for
  the user, `●` for replies, `✻` copper pulse while working) and the CLI's own framed reply box —
  a 1px `--tui-hair` rounded frame with a `>` prompt, breathing slate-blue when a question waits.
  Enter still submits; the send button is gone (the CLI has none). `ICON_SEND` and all `.msg`/
  `.chat` chrome styles deleted.

Follow-up in the same session: with the header hairline gone, the 14px card top margin read as
dead white space, so the card tucks up to 4px under the header (`margin: 4px 14px 14px` — the 50px
header already carries the vertical air). Same 4px under the tabs-mode strip, which was checked and
reads fine; the hover-strip offsets moved with it.

Both `working.html` and `big-picture-design.html` carry every change; invariant diff (title + extra
session rows) verified. Checked in the browser in both themes: flat sidebar, card-only geometry,
strip alignment measured to the pixel (card top + 10 → card bottom − 10), reply flow exercised
end-to-end (echo → working → settled).
