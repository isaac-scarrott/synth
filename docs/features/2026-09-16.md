# 2026-09-16

## 0.45.0 ships — a window past 80% or 95% says so once

A minor release carrying one app change: usage alerts. Any agent window with a ceiling raises a
card as it crosses 80% and again at 95% — "Current session at 81%", the agent on the who-line, the
reset countdown, and **View** onto the Usage board. The 80% card is ambient and drains away, the
95% one sticks. Once per window, one card per agent per urgency, silent while the board is open.
Settings → Usage → Usage alerts is on by default and turning it off also stops the background
poll. A minor rather than a patch because Synth now speaks unprompted where it didn't before.

## 0.45.1 ships — Inspect connects

A patch carrying one fix: the inspect pane opened onto the DevTools frontend's own "disconnected"
banner. The frontend is served as an ordinary `http://` page off the instance's CDP endpoint, so
its socket to `/devtools/page/<id>` carries an `Origin` header, and Chromium 111+ answers any
origin-bearing DevTools socket with 403 unless that origin is named in `--remote-allow-origins`.
The switch now names the endpoint's own origin and nothing else, so the anti-DNS-rebinding guard
still stands for every other page. Synth's own CDP clients send no `Origin`, which is why the MCP
browser tools kept working throughout and only Inspect broke. The engine self-check grew
`devtools-frontend-origin`, with a foreign origin as the control so the check cannot pass vacuously.
