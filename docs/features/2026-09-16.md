# 2026-09-16

## 0.45.0 ships — a window past 80% or 95% says so once

A minor release carrying one app change: usage alerts. Any agent window with a ceiling raises a
card as it crosses 80% and again at 95% — "Current session at 81%", the agent on the who-line, the
reset countdown, and **View** onto the Usage board. The 80% card is ambient and drains away, the
95% one sticks. Once per window, one card per agent per urgency, silent while the board is open.
Settings → Usage → Usage alerts is on by default and turning it off also stops the background
poll. A minor rather than a patch because Synth now speaks unprompted where it didn't before.

`CFBundleVersion` 758, tag `v0.45.0`. Both artifacts notarized in separate submissions and
stapled, then verified with no credentials and quarantine set, the way a browser download arrives:
the dmg assessed `accepted / source=Notarized Developer ID`, the app inside it the same with
`stapler validate` passing on its own, and the Sparkle zip likewise after extraction — reporting
`0.45.0` / `758` from its own `Info.plist`. The appcast's newest item is 758 with `edSignature` on
all 18 enclosures; the delta from 0.44.0 (755) is 1.0 MB, the largest 1.5 MB, against a 165 MB
full download. No `synth-site` push — nothing under `site/` changed since 0.44.0.

One commit landed on `main` after the tag was cut and is therefore **not** in this build: `9551d64`
"Inspect connects — the DevTools frontend's own origin is allowed". It ships with the next release.
