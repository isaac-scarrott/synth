# 2026-10-06

## Status indicators swap without the entry pop

Supersedes the entry pop in "Sidebar indicators: soft glow + entry pop, one shared axis"
(2026-07-06). The `.ind` slot no longer animates in: a status change repaints the slot in one
frame, in `working.html` (no `ind-in`) and natively (`Ind` is the plain 16×16 slot).

The native pop was a `.spring(response: 0.24, dampingFraction: 0.6)` on scale and opacity, replayed
by every state swap because each status is its own view identity. The spring ran about 0.5s at
display rate, settling well below visible amplitude for most of it, and each frame re-rendered every
one of `Beat`'s 21 dots in both the sidebar and the tab strip. One `idle→working` cost ~1,240
`DisplayList.Version` ids and `working→needsInput` ~1,080; an agent cycling states across several
rows spent hundreds a second. Without the spring each swap is one render: `idle→working` ~220,
`working→needsInput` 36, `→idle` 30. Fewer animations was also asked for directly.
